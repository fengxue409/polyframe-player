# P9 交付总结：吸收 GYING 功能批次（2026-10-26）

> 需求来源：参考「观影 GYING」（教父.com，见 `docs/GYING-功能研究与吸收建议.md`）吸收功能。
> 本批交付：分类浏览/更新流、剧集连播、收藏追更、继续观看（RPC 冒烟 28/28 全绿）。

## 1. 功能总览

| 功能 | 入口 | 说明 |
|---|---|---|
| 分类浏览 / 今日更新流 | 发现页「分类」tab | `ac=detail&pg=N` 翻页扇出全部启用源站；大类（电影/剧集/动漫/综艺）按 type_name 关键词过滤（站间类型 ID 不互通，不做 t= 透传）；年份精确匹配；「今日更新」走苹果CMS `h=24` 参数；按站内更新时间降序；加载更多翻页追加 |
| 剧集连播 | 详情弹层 / 收藏片源弹层选集起播 | 整组剧集入队（`playFromQueue`），PlayerView `ended`（hls）/ `mpvState.eof`（mpv）自动播下一集；播放页「下一集 ▶ 集名」快捷按钮 |
| 收藏追更 | 媒体库收藏 tab「检查更新」 | `catalog.favorite.refresh` 回拉片源站 `ac=detail` 对比集数，快照变多即写回；收藏卡显示「+N 集」徽章（打开片源弹层后清除）；幂等（无新增不上报） |
| 继续观看 | 媒体库收藏 tab 顶部行 | `watch_progress` 表每收藏一条（INSERT OR REPLACE）；PlayerView `timeupdate` / mpvState 5s 节流上报；续播重建队列并 seek（>15s 且距片尾 >30s 才跳） |
| 换源（多站对比切换） | 详情弹层「片源（N 站）」chips | 聚合卡片保留各站条目（站名 + 清晰度/集数），详情弹层可一键切到另一站重拉剧集——对标 LibreTV「跨源同名聚合：展开即可比较和选择各来源」。此前聚合只显示「▲N 站」计数却无法选源 |

## 2. 协议与数据模型（增量）

```
catalog.category { pg, hours?, category?, year? }        → { cards[], failures[], page, hasMore }
catalog.favorite.refresh { id? }                          → { checked, updated[{favoriteId,name,siteName,oldCount,newCount,added}], failed[] }
catalog.favorite.progress.set { favoriteId, episodeName, episodeUrl, position, duration }
                                                          → { saved }（联动 last_played_at）
catalog.progress.list { limit? }                          → { items: WatchProgress[] }（JOIN favorites）
```

- pf-parser::cms 新增 `page_url`（翻页 + h 参数）与 `category_matches`（大类关键词，顺序敏感：动漫→剧集→综艺→电影，防「纪录片」串门）
- Card 新增 `updateTime`（站内 vod_time 聚合最大值，更新流排序键）
- pf-engine 新表 `watch_progress`（favorite_id PK / episode_name / episode_url / position_sec / duration_sec / updated_at），删收藏级联清进度

## 3. 前端（catalog store 增量）

- 分类：`loadCategory(reset)` / `setCategoryFilter`；DiscoverView 模式 tab（搜索/分类）+ 筛选 chips + 加载更多
- 连播：`playFromQueue(episodes, index, title, favoriteId?)` / `playNext` / `clearQueue`；详情弹层与收藏弹层选集均整组入队
- 进度：`reportProgress`（PlayerView 节流调用）/ `refreshContinueWatching` / `resumeProgress`（重建队列 + `pendingSeek` 由 PlayerView canplay 消费）
- 追更：`refreshFavoriteUpdates(id?)` + `favUpdates` 徽章字典
