# P42 · 撤掉顶栏 / 页头，控件归并到工具条

> 需求（原话）：**「这部分都移除，其中的亮系和暗系切换放左下角；片库、收藏、刷新放筛选边上」**
> ——截图圈的是「顶栏（首页 · 聚合推荐 · 多站片源 / 月亮 · 内核在线）+ 影视库页头（真实数据 · N 个源站聚合 / 片库 · 收藏 · 刷新）」两块。

## 1. 结论先行

首页上方原来有 **两道横条**（全局顶栏 56px + 页头 48px），都在抢竖向空间：

| | 改动前 | 改动后 |
|---|---|---|
| 首张海报 top（1440×900） | 445px | **250px** |
| 首屏完整海报行 | 1 | **2** |
| 内容顶到窗口顶 | 否（104px 横条） | **是** |

做法不是「删控件」，而是**把控件搬到它该在的地方**：

| 原来在哪 | 现在在哪 |
|---|---|
| 顶栏：页面标题 + 副标题 | 删除（侧栏高亮已表达「我在哪」） |
| 顶栏：月亮/太阳（皮肤切换） | **侧栏左下角**，「设置」上方的常驻项 |
| 顶栏：内核状态胶囊 | 侧栏左下角那行「● 内核在线」（原本就有，现在成了唯一状态位） |
| 页头：片库 / 收藏 | **工具条右侧**，与刷新、筛选同组 |
| 页头：刷新 | 同上（30px 图标按钮，与筛选同高） |
| 页头：真实数据 / N 个源站聚合 | 真实态直接删除；**演示态**降级为结果栏里一枚「演示数据」小徽章 |

## 3. 顺手必须改的两处耦合

**① 播放卡纵向预算（`PlayerView.vue`）**
`--pf-card-room` 里含「顶栏 51」，顶栏没了还留着就会**白白少 51px 视频高度**：

| 变量 | 原值 | 新值 | 依据 |
|---|---|---|---|
| `--pf-card-room` | 144px | **93px** | 上留白 16 + 余量 61 + 下留白 16 |
| 抽屉展开 | `dock-h + 104px` | **`dock-h + 53px`** | 抽屉 + 16 + 16 + 余量 21 |

实测（`.probe/probe-player-budget.mjs`）：

| 视口 | 卡片宽 | 视频高 | 卡片底 | 视口 | 结论 |
|---|---|---|---|---|---|
| 1440×900 | 830 | 448（原 397） | 779 | 900 | 无滚动 |
| 1440×900（抽屉开） | 830 | 307 | 638 | 抽屉顶 675 | 间距 37px，不遮挡 |
| 1024×700 | 450 | 234 | 621 | 700 | 无滚动 |

**② 文案与注释**
设置页「顶栏右侧的月亮 / 太阳按钮与之等价」→「左下角「暗色 / 亮色」按钮与之等价」；
SideNav 里两条讲顶栏的注释同步改掉。

## 4. 为什么不给其它页面补标题

TasksView / HistoryView 自带 `page-head`（「任务（N）」「最近观看」），不受影响；
设置 / 发现 / 媒体库 / 解析 / 网盘 / 磁力本来就是「内容即标题」（搜索框、tab、卡片分组开头），
强行补一个 `h2` 只会把 P41 刚省下来的 56px 又还回去。

## 5. 踩坑

**① 工具条右半边长出来以后，类型胶囊会被压碎。** 原先 ≤480px 给 `.qb-types` 设 `flex: 1 1 0`
是为了「筛选」不折行；现在同一行多了 片库/收藏 + 刷新，胶囊被压到 90px，
「电影」被切成半个字。改成**让右半边整体折到下一行**（并删掉 `flex: 1 1 0`），
类型条按内容宽度排满一行，反而比原来更完整。

**② 删 CSS 别用「从 `.xxx {` 删到下一个花括号」这种朴素规则。** 全局 `.dot` 被
HistoryView / ParseView 复用，删状态胶囊时只能删 `.status` 与 `.st-*`，`.dot` 必须留。
