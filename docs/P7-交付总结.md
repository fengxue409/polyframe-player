# P7 交付总结：影视发现与片源聚合（2026-10-26）

> 需求：收集视频库（在线搜索 + 热度信息）、收集视频源（在线切换 + 手动补充）。
> 形态：CMS 采集站聚合（苹果CMS V10 API，LibreTV/MoonTV 同款协议），零 API key、零外部服务。

## 1. 功能总览

| 功能 | 入口 | 说明 |
|---|---|---|
| 在线聚合搜索 | 发现页搜索框 | 并发扇出全部启用采集站，同名影片按 `normalize(片名)+年份` 归并成卡片 |
| 热度信息 | 卡片 ▲N 站徽章 | 收录站数（聚合统计，无需 TMDB key）；排序按收录数降序 |
| 详情与选集 | 卡片「查看片源」 | 元数据（年份/分类/导演/主演/简介/更新时间）+ 按播放源分组的选集网格 |
| 片源在线切换 | 详情弹层各分组 / 收藏片源弹层 | 同片不同站=不同编码版本（不走 P2SP 字节聚合），选另一站的集直接重新起播 |
| 收藏入库 | 卡片/详情「收藏」 | 聚合 ≤3 站剧集快照；媒体库「收藏」tab 展示，一键播放第一片源 |
| 手动补充片源 | 收藏片源弹层 | 支持 `名称$URL#名称$URL` 或每行一个裸 m3u8/直链（复用 CMS play_url 解析） |
| 源站管理 | 发现页「源站」按钮 / 设置页卡片 | 增删改查 + 启停（停用不参与搜索）+ 测速（延迟/最近成功时间落库）+ 出厂 5 源播种 |

## 2. 协议与数据模型

### CMS 采集站 API（苹果CMS V10）

```
探测/测速  GET {api}?ac=list&pg=1                  → {code, list:[...]}
搜索      GET {api}?ac=detail&wd={kw}              → 一步拿全 play_url（首选）
回退      GET {api}?ac=videolist&wd={kw}           → 部分站仅支持列表搜索
详情      GET {api}?ac=detail&ids={vod_id}         → 完整元数据 + 分组剧集
剧集分组  vod_play_from = "m3u8$$$xigua"           ←→ vod_play_url 按 $$$ 对应分组
单集      "第01集$https://.../1.m3u8#第02集$..."   （$ 按首个切分，容忍 URL 含 $）
```

容错：`vod_id` 数字/字符串弹性解析；全字段 serde default（站点实现参差不炸）；from 缺失「播放」兜底；裸 URL 序号命名。

### RPC（camelCase，与 packages/shared 同构）

```
catalog.source.list / add（先探测失败拒入库）/ update / remove / test（延迟回写）
catalog.search {q}                     → {cards[], failures[]}（单请求 4.5s 超时）
catalog.detail {api, vodId, sourceId?} → {detail}（分组剧集）
catalog.favorite.list / add{card|detail} / remove
catalog.favorite.sources {id}          → 片源快照列表
catalog.favorite.source.add {favoriteId, urls, label?} / remove {sourceId}
catalog.favorite.touch {id}            → 最近播放记账
core.hello 新增 proxyToken（/pic 海报透传拼 URL 用）
```

### SQLite 三表（pf-engine catalog_store，随 CacheStore::open 建表）

- `catalog_sources`（id/api UNIQUE/name/enabled/builtin/latency_ms/last_ok_at）
- `favorites`（name/year/type_name/remarks/poster/content/last_played_at）
- `favorite_sources`（favorite_id/site_name/api/vod_id/episodes JSON 快照/origin=search|manual）

归并：`find_favorite_by_key`（normalize+year）；去重：`find_favorite_source_by_site`（同收藏+同 api+同 vodId）。

## 3. 关键实现点

- **pf-parser::cms**：纯解析零网络，4 组单测（detail 形态/边界容错/聚合键/URL 构造）
- **pf-core::catalog**：网络编排（reqwest http1_only + 连接 5s + 请求 4.5s 超时）；搜索失败站进 `failures` 回显；搜索成功顺带回写源站延迟/最近成功时间（测速数据自然积累）
- **pf-proxy /pic**：海报透传 `/pic/{token}?u=`，同 token 门禁 + percent-decode + http(s) 白名单 + 控制字符拒绝 + 10MB 上限 + 同源 Referer + 浏览器 UA（防盗链）+ 24h 缓存头
- **桌面端**：`stores/catalog.ts`（搜索/详情/收藏/海报 URL 组装）；DiscoverView v-show 保活（切页保留搜索结果与弹层）；起播复用 `player.playTask`（task.create → 跨页起播，缓存档位沿用设置页默认）

## 4. 已修 bug（E2E 抓真雷）

| bug | 现象 | 根因 | 修复 |
|---|---|---|---|
| UI 收藏必失败 | toast "An object could not be cloned." | Vue reactive Proxy 对象不能过 Electron IPC 结构化克隆 | `addFavorite` 入口 `JSON.parse(JSON.stringify())` 深拷贝为普通对象 |
| /pic 400 invalid u | 海报透传全挂 | query 参数 `u` 忘了 percent-decode（`http%3A%2F%2F…` 过不了 http 前缀校验） | pf-proxy 新增最小 percent_decode（%XX + 容忍截断） |

## 6. 使用说明（网页端同步参考）

1. 设置页（或发现页「源站」）确认源站可用（测速），停用失效站
2. 发现页搜索片名 → 卡片 ▲N 站 即热度 → 「查看片源」选站选集起播（走既有下载引擎：三档缓存模式/多源聚合对 CMS 片源同样生效）
3. 「收藏」入库后到媒体库收藏 tab 管理；片源弹层可手动补充直链（离线资源/自建源）
4. 手动补充格式：`第01集$http://x/1.m3u8#第02集$http://x/2.m3u8` 或每行一个裸 URL
