# 观影 GYING（教父.com）功能研究与吸收建议

> 调研日期：2026-10-26。官方域名 `教父.com`（xn--wcv59z.com）/ `hgeme.com` 均有浏览器反爬验证，
> 无法直接抓取页面，本文基于多个第三方导航/测评站（青城导航、3W导航、Greasy Fork 脚本等）交叉整理。
> GYING 前身：片库网 / 无名小站（btnull），老牌高清影视聚合站。

## 1. GYING 功能画像

| 模块 | 功能点 |
|---|---|
| 资源覆盖 | 电影/剧集/动漫/综艺/纪录片，每日更新，新片与经典老片并重，4K 原盘/1080P/720P 多画质 |
| 搜索 | 关键词直达播放或下载页（URL 形如 `/search?q=片名&type=&mode=1`）；热搜榜；今日更新列表 |
| 分类筛选 | 按类型（动作/悬疑/科幻/韩剧/美剧…）、地区、年份、评分多维筛选与排序 |
| 在线播放 | 多线路切换（主线路慢切备用）；内置 VIP 解析接口；弹幕互动 |
| 下载 | 磁力/BT 种子直取；百度网盘/阿里云盘/夸克网盘多网盘链接；支持 IDM 抓取 |
| 详情页 | 导演/主演/剧情简介/评分/压制组信息/清晰度选项；同片多压制版本可选 |
| 用户体系 | 收藏夹管理、观影记录同步、多端访问；部分功能需登录（临时邮箱可注册） |
| 社区 | 用户评论区补充网盘资源，形成协作生态；用户可发布资源 |
| 其他 | 界面干净无弹窗、资源仅索引不存储、域名不定期更换（发布页引导） |

## 3. 吸收建议（P8 候选，按性价比排序）

1. **分类浏览 + 更新流**：`ac=list&t={分类}&pg={页}` 翻页聚合，发现页加「分类」tab；
   筛选维度对齐 GYING（类型/地区/年份），排序沿用收录站数。
2. **剧集连播**：把 catalog 详情的剧集序列接入 P3 series 队列，播完自动下一集 + 「下一集」按钮。
3. **追更**：收藏片源后台回拉 `ac=detail` 对比集数，有更新时在收藏卡上标红「+N 集」。
4. **观影历史页**：基于 `last_played_at` + 进度记账做「继续观看」行（含未看完的跳转续播）。
5. **热门榜**：首页聚合卡片按收录站数/近期播放频次出「热门推荐」行。
6. **评分增强（可选）**：TMDB key 可配时叠加评分与背景图（与 P7 后续方向一致）。
7. **磁力源支持（中长期）**：GYING 的核心资源形态是磁力/网盘；pf-core 的 P2SP 引擎若增加 BT 后端
   （如 libtorrent 绑定），可把磁力作为第五种片源类型，与现有 m3u8/直链并列。

## 4. 借鉴的产品原则（非功能）

- **零门槛**：GYING 免注册免登录即用核心功能 → PolyFrame 本地化做得更彻底，继续保持。
- **纯净**：无弹窗广告、界面克制 → 聚合结果页避免信息过载，卡片密度参考 GYING 海报墙。
- **域名容灾**：GYING 用发布页 + 多备用域名对抗失效 → 源站管理可加「一键测速并停用失效站」
  批量操作（当前已可逐个测速，可加全量巡检按钮）。
