## 2. IDM 动态分段（pf-engine）

### 2.1 设计

MP4 任务调度单元从「静态 4MiB 块逐片取件」升级为 IDM 式动态分段（[pf-engine/src/lib.rs](../apps/core/crates/pf-engine/src/lib.rs)）：

- **认领块** `Claim { next, stop_at }`：CAS 游标 + 可前移终点的连续 seq 区间。空闲 worker 调 `largest_window_run()` 取**调度窗口内最大剩余连续 run** 对半分认领前半段
- **在途窃取** `try_steal_claim()`：todo 清空后，把剩余量最大的在途块剩余段对半分接管（原块 `stop_at` swap 前移至切分点）；剩余 ≥ `IDM_STEAL_MIN`（4 片 = 16MiB）才值得切
- **块只是调度范围**：认领块内仍逐片走既有 `fetch_on_sources` —— 换源/重试/健康度记账完全不变；窗口随播放头实时校验，出窗剩余片归还 todo 重排；分片存储（`{seq:08}.bin`）与断点续存零改动
- HLS 任务照旧逐片调度（`Pick::Seg` 分支未动）

### 2.2 效果

快源先完成自己的半段后自动窃取慢源半段，天然负载均衡；无静态切块的尾部倾斜问题。

## 3. 合并导出（task.exportInfo / task.export）

### 3.1 协议（packages/shared）

```ts
'task.exportInfo': { params: { taskId }; result: { ext: string; done: number; total: number } }
'task.export':     { params: { taskId; outPath }; result: { path: string; bytes: number; segments: number } }
```

### 3.2 引擎实现（纯 Rust，零外部依赖）

- **TS**：分片按 seq 二进制 concat → `.ts`
- **fMP4**：EXT-X-MAP init 段前置（[pf-parser](../apps/core/crates/pf-parser/src/lib.rs) 新增 `MediaIR.map_uri` 捕获，导出时重新拉取 init）再拼 `.m4s` → `.mp4`
- **MP4 直链**：块按 seq 回拼原始文件
- 格式判定：嗅探首缓存片首字节（`0x47` = TS 同步字节，否则 mp4）
- 安全落盘：`.part` 先写 → rename；未完成缓存允许导出（warn 日志）；未知任务/空缓存明确报错

### 3.3 桌面端编排

任务页「导出」按钮（有缓存且非 dash 显示）→ 主进程 `pf:export` IPC：`task.exportInfo` 探测 → 保存对话框（任务标题派生文件名 + 扩展名过滤）→ `task.export`（10 分钟长超时）→ player store 日志反馈。preload 暴露 `window.polyframe.exportTask(taskId)`。

## 4. 站点提取兜底（pf-parser + pf-engine）

两级提取（[lib.rs extract_fallback](../apps/core/crates/pf-engine/src/lib.rs)）：

1. **内置页面扫描**：`pf_parser::scan_html` —— 零正则，按引号字面量枚举 + 扩展名命中（m3u8/mpd/mp4）+ URL 合法性预过滤（拒空白/尖括号，防跨引号垃圾段）+ 相对路径 `resolve_url` 归一 + 去重保序上限 20；`extract_from_page` 抓页面后扫描，候选逐个尝试（上限 5）
2. **外挂 yt-dlp**：`find_ytdlp()` 查找 pf-core.exe 同目录（安装包可随附）→ PATH；`yt-dlp -g --no-playlist URL` 取直链（90s 超时，stderr 末三行进错误）

挂载点：`probe_and_start` 主源 **HLS 解析失败**时进入兜底（MP4 主源不走）；过程全部走引擎日志。UI：播放页 `url-hint` 提示支持范围与 yt-dlp 解锁说明。

## 5. Windows 安装包（electron-builder）

### 5.1 配置（apps/desktop/package.json `build` 字段）

- **双产物**：NSIS Setup（`oneClick: false`，目录可选 + 桌面/开始菜单快捷方式 + 卸载器）+ portable 免安装单 exe
- **内核内置**：`extraResources` 把 `apps/core/target/release/pf-core.exe` + `apps/core/vendor/mpv/libmpv-2.dll` 放入 `<install>/resources/pf-core/`
- **打包分支定位**：[electron/main/index.ts](../apps/desktop/electron/main/index.ts) `locateCoreBin` 补 `process.resourcesPath/pf-core/pf-core.exe`，优先级：`PF_CORE_BIN` 环境变量 > 打包 resources > dev release > debug
- 图标：[build/icon.ico](../apps/desktop/build/icon.ico)（256px 圆角渐变 + 播放三角；生成脚本思路：纯 Node 手写 PNG chunk + ICO 打包）
- `dist` 脚本：`electron-vite build && electron-builder --win --x64`

### 5.2 产物

| 文件 | 体积 | 说明 |
|---|---|---|
| `apps/desktop/release/PolyFrame Player Setup 0.1.0.exe` | ≈161 MB | NSIS 安装向导 |
| `apps/desktop/release/PolyFrame Player 0.1.0.exe` | ≈144 MB | portable 免安装 |
| `apps/desktop/release/win-unpacked/` | — | 解包目录（E2E 用） |

libmpv-2.dll 116MB 内置；未签名（SmartScreen 首次运行需「更多信息 → 仍要运行」）。

## 8. 后续注意

- 安装包升级分发：改版本号 `apps/desktop/package.json version` 后重跑 `pnpm dist`（blockmap 支持增量更新，但未配 auto-updater）
- yt-dlp 随包分发：把 yt-dlp.exe 拷入安装目录即可解锁站点提取（打包配置加一条 extraResources 即可）
- DASH 任务导出暂不支持（协议归并未做，`export_ext` 明确报错）；直播流导出按快照分片处理
- 签名：正式分发前建议上代码签名证书消除 SmartScreen 告警
