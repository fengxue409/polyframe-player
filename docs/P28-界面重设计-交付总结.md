# P28 全站界面重设计 · 交付总结

目标：统一全站视觉语言、重建层次、改善信息密度与可读性，**不改动任何业务逻辑**。
范围：10 个路由页 + 全局壳层 + 详情弹层。运行层（Vue router 自研、单滚动容器、mpv 表面显隐、P24/P25 高度预算）全部原样保留。

## 1. 起因：旧界面为什么必须重做

| 现状问题 | 具体表现 |
| --- | --- |
| token 太少，色值散落 | `#1a2130 / #1d2b45 / #2a3245 / #182238 / #9cc0ff / #8fa8cf` 在 6+ 个组件里各写一遍；`--muted`、`--border`、`--r-sm` 在 DiscoverView/CatalogDetailModal 里**从未定义**，全部走 `var(--muted, #8b8b8b)` 的兜底值 |
| 正文对比度不足 | `--text-dim: #7c8699` 在 panel 上只有 4.1:1，未过 AA |
| 排版语言不统一 | 中文标题用了 `text-transform: uppercase`（对中文无效）；日期/来源/集数挤成两三行碎信息 |
| 重复实现 | toast 在 4 个文件里各定义一份；`.empty`、`.head`、`.badge`、`.spin` 各页各一套 |
| 基础体验缺失 | 没有统一滚动条、没有 `focus-visible` 焦点环、没有 `prefers-reduced-motion`、没有骨架屏 |
| 具体页面硬伤 | 首页分类带 emoji + 卡片区与页头重复的 tab 组；发现页未定义变量 + 三行元信息；设置页 13 处内联 `style`；解析页未起播时一整块全屏黑洞；网盘页「表格空行 + 空提示」双份空态；弹层自带一套 `.modal` 把 z-index 从 60 降到 50，并关掉了背景模糊与入场动画 |

## 2. 地基：App.vue 设计系统（五层）

1. **token**：`--bg/--bg-nav/--panel/--panel-2/--panel-3/--line/--line-2/--text/--text-dim/--text-faint`、`--accent`（+ `-soft/-line/-ink`）、`--ok/--warn/--danger/--info` 各带 `-bg/-line`、圆角 `--r-sm..xl`、间距 `--sp-1..10`、字号 `--fs-2xs..2xl`、阴影 `--shadow-1..3`、焦点 `--ring`、动效 `--t-fast/base/slow + --ease`、层级 `--z-sticky/mask/toast`。
2. **基础元素**：`button/.btn`（`primary/ghost/danger/sm/xs/mini`）、`input/textarea/select`、`table/th/td`（表头吸顶 + 行 hover）、`::-webkit-scrollbar`、`focus-visible`。
3. **材质/排版**：`.card`、`.page-head`、`.kv`、`.alert/.notice`、`.progress`、`.spin/.spinner`、`.skeleton`、`.empty`、`.toast`、`.modal-mask/.modal`。
4. **组件原语**：`.badge`（5 种语义色）、`.chip`、`.segmented`。
5. **工具类 + 响应式**：`.dim/.small/.mono/.center`、`prefers-reduced-motion`、三档断点。

对比度按 panel `#121722` 核算：text 15.0 / dim 7.1 / faint 4.9，全部 ≥ 4.5。

## 3. 逐页改动

### 壳层 App.vue
- 顶栏改 `pageMeta`（标题 + 副标题），`h1` 不再与页面内标题重复；内核状态胶囊按 `st-online/starting/error` 语义化 + 呼吸点。
- toast 收成全局唯一定义 + `<Transition name="pf-toast">`。
- `.content` 明确为**全应用唯一纵向滚动容器**（`scrollbar-gutter: stable`，切页不抖宽度）。

### SideNav
- 10 项平铺 → **分组导航**：浏览（首页/发现/播放）· 我的（历史/媒体库/任务）· 片源（解析/网盘/磁力）· 设置钉底。
- 新 SVG 品牌标（渐变方块 + 播放三角）+ `PolyFrame / PLAYER` 双行。
- 选中态：左侧 2px 竖条 + `--accent-soft` 底 + `--accent-ink` 字；≤1000px 收成 68px 图标轨（分组标题退化为分隔线），≤640px 58px。

### 首页 HomeView
- 去掉分类 emoji（与侧栏同语言）；`.sec-head` 删掉与页头重复的「热门/最新/收藏」tab，只留 `h3 + 模式徽章 + 计数`。
- 搜索栏一体化：图标 + 透明输入 + `focus-within` 高亮整条。
- 卡片 `role=button/tabindex/keydown` 键盘可达；封面底部渐隐 + 时长胶囊（半透明深底 + blur）。
- 轮播：底部 2px 进度条（5s linear）、标签胶囊化、左右箭头 hover 才出现、左深右浅遮罩。

### 发现 DiscoverView
- 清理所有未定义变量（`--muted/--border` → 语义 token）。
- 搜索/分类加载从「一行文字」改为**骨架卡片网格**。
- 三行元信息压成一行 `.movie-sub`（`·` 分隔）；模式切换用全局 `.segmented`；空态用全局 `.empty`。

### 历史 HistoryView
- `.head` → 全局 `.page-head`（标题 + 计数说明 + 动作组）。
- 行改 `grid[132px | 1fr | auto]`，hover 位移 2px；≤860px 变两行 grid-areas。
- 徽章改 `.badge.ok/.info`，空态/骨架统一。

### 媒体库 LibraryView
- `.tabs/.tab` → `.lib-bar` + 全局 `.segmented` + `.lib-tools`。
- 两处空态改全局 `.empty`（+ 主按钮），任务状态徽章接语义色，播放按钮 46px 圆形 blur。

### 任务 TasksView
- 页头改 `.page-head`（`任务（N）` + 说明 + 刷新）。
- 列宽重排（`26% / 20% / 306px`，`min-width: 820px`）；≤1100px 隐藏「保留至」、≤860px 隐藏「速度」。

### 网盘 NetdiskView
- 表格 `v-if="items.length"`，否则渲染**一个** `.empty`（读取中 → spinner；未选来源 🗂；目录为空 📂），删掉原先并排的「空表格 + 提示」。
- `.badge.vid` → `.badge.ok`；面包屑/文件名剥离按钮默认外观；≤1000px 单列堆叠，≤640px 隐藏「修改时间」。

### 磁力 MagnetView（本轮重写）
- 100+ 字的一坨提示拆成 3 条要点；输入条改「一体化工具条」（图标 + 无边框输入 + 内嵌主按钮，`focus-within` 高亮整条），≤520px 退化为独立输入框 + 全宽按钮。
- 状态徽章 5 态接语义色（待元数据 info / 下载中 accent / 暂停 warn / 完成 ok / 失败 danger）；进度条用全局 `.progress`，按状态换填充色，元数据阶段用流动光条表示「在动但不可测」。
- 行改 `grid[1fr | auto]`，≤720px 操作按钮落到第二行；选集面板宽屏双列、当前集高亮，去掉了内层 `max-height + overflow`（遵守「视图内不开第二个滚动条」）。

### 解析 ParseView
- 表头内联 `style="width:…"` → `.c-name/.c-st/.c-ops`。
- 播放舞台 `width: min(100%, 58vh*16/9)` + `radial-gradient` 舞台底（不再是一块全屏黑洞），真正内嵌播放才纯黑。
- 空态加圆形链接图标 + 已支持站点 chips；`.hint` 限宽 92ch。

### 设置 SettingsView
- 13 处内联 `style` 全部换成语义类（`.note/.note.foot/.mt-3/.tight-top/.builtin-tag/.sub-title/.dm-row.top/.grow`），内联残留 0。
- 新增三组小标题（运行时与存储 / 内容源 / 弹幕）；`.note` 行高 1.7、`.kv` 加分隔线、`.cap-input` 右对齐。

### 播放 PlayerView（只动样式层）
- 全部硬编码色改 token（`#1d2b45→--accent-soft`、`#1a2130→--panel-3`、`#16283c/#69a8ff→info`、`#33290f→warn`、`#3a1a1f→danger`、`#14321f→ok`…）。
- 控制条压成 28px 高的紧凑按钮组（`--panel-2` 底，active 用 accent 三元组），mpv 暂停按钮并入同一套；`.seek-row` 单独成行。
- 调试面板：源状态徽章/日志级别全部语义色，指标行等宽数字，日志 `<ul>` 清掉默认内外边距。
- 侧栏：tipo/dir 用 `.badge`，进度条换全局 `.progress`，导演/主演改 `<dl class="credits">`（与弹层同构），空态加图标+标题+副文案，去掉对全局 `.empty` 的误用（`class="dim small empty"` 会把一行字撑成 40px 内边距的大空态）。
- 关键约束**逐字保留**：`--pf-card-chrome`（176 / mpv 222）、`--pf-card-room` 194、`.video-wrap` 由高度反推宽度的公式、`.card.player` sticky 与 `debug-open` 取消吸顶、`max-height:620px` 降级、窄屏三行 grid-areas、`.stage display:contents`。

### 详情弹层 CatalogDetailModal（本轮重写）
- **删掉自带的一套 `.modal-mask/.modal`**：它把 z-index 从 `--z-mask(60)` 压到 50，还覆盖掉了背景模糊与 `pf-fade/pf-pop` 入场动画；现在只保留 `.detail-modal` 的尺寸与内部滚动。
- 头部改 `grid[132px | 1fr]`；标题 + ★评分徽章；`年份 · 分类 · 状态 · 更新时间` 压成一行（状态用 info 色提亮）；导演/主演改 `<dl class="credits">`。
- 简介从 `max-height:120px + overflow:auto` 改为**行钳制 5 行 + 展开全文**（弹层内不再出现第二个滚动条）。
- 片源 chips 用全局 `.chip`（active 走 accent 三元组）；剧集区改 `线路名 + N 集 + 从第 1 集连播`，剧集网格 `auto-fill minmax(66px,1fr)`，当前集高亮。
- 首屏骨架：海报块 + 4 条文字条，`min-height:260px` 贴近真实高度，数据到位不跳高。
- 关闭按钮改 26×26 图标按钮；≤720px 收窄，≤560px 单列。

## 4. 验证

```bash
export PATH="/c/Users/<you>/AppData/Roaming/npm:/c/Users/<you>/.cargo/bin:$PATH"
pnpm -r typecheck                                  # 通过
pnpm --filter @polyframe/desktop build              # 通过（CSS 138.35 → 139.30 kB）
node ui-snapshot.mjs                                # 1440x900 + 820x620，各 10 页
node ui-snapshot.mjs 420x860                        # 手机断点
PF_UITEST=1 node ui-snapshot.mjs 1440x900           # 额外抓详情弹层与磁力任务行
```

`ui-snapshot.mjs`（项目根，新增）用项目自带 Electron 当无头浏览器加载 `out/renderer`，逐页点导航截图，并顺手做两项**客观体检**：

- 横向溢出：遍历 `.content *`，`scrollWidth > clientWidth` 且 `overflow-x: visible` 即记录。三档视口全部为 0（唯一报告项是轮播轨道 `div.slides`，`translate` 驱动的假阳性，不影响文档宽度）。
- 关键区域矩形：`.video-wrap / .card.player / .info-side / .card.debug`。1440×900 下播放卡 814×764、调试面板顶 852 − 卡底 836 = **16px**，与 P25 验收判据一致。

截图里确认的细节：磁力行在 1:1 裁切下按钮文字/边框完整（整页缩略图看像被裁，实为缩放失真）；弹层在 880×606 下无内部滚动、手机 380 宽下正常折行。
