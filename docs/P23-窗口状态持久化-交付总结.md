# P23 窗口状态持久化 — 交付总结

**需求**：应用退出时记录窗口位置、尺寸、最大化/最小化状态，下次启动还原；首次运行用默认值；读写失败要容错，不能影响启动与退出。

**交付日期**：2026-10-30

| 项 | 结果 |
|---|---|
| 状态文件 | `%APPDATA%/PolyFrame Player/window-state.json`（`app.getPath('userData')`），环境变量 `PF_WINDOW_STATE` 可覆盖（E2E 隔离用） |

## 2. 实现

新文件 `apps/desktop/electron/main/window-state.ts`：

- `windowStatePath()` —— `PF_WINDOW_STATE` > `userData/window-state.json`。
- `defaultWindowState()` —— 主屏 `workArea` 居中；拿不到屏幕信息就左上角兜底（不抛）。
- `loadWindowState()` —— 先 `existsSync`，再 `JSON.parse`，逐字段校验（`Number.isFinite` + 宽高 > 0），布尔位只认 `true`；任何异常 `catch` 后 `console.warn` + 返回默认值。
- `saveWindowState()` —— `mkdir -p` → 写 `${file}.tmp` → `rename` 原子替换；失败只告警并清掉临时文件。
- `trackWindowState(win, initial)` —— 事件订阅 + 快照 + 节流落盘。

`apps/desktop/electron/main/index.ts` 的 `createWindow()`：

- 构造参数直接用 `saved.bounds`（`minWidth/minHeight` 与模块共用常量，避免两处漂移）；
- `show: false` + `ready-to-show` 里「先 `maximize()` 再 `show()`」——最大化赶在首帧前生效，不会先闪一下普通尺寸；
- 3s 兜底定时器：`ready-to-show` 依赖首帧渲染，页面异常时保证窗口一定露面；
- `trackWindowState()` 挂在构造之后，`close` 同步 flush。

## 3. 三个必须踩准的细节

### 3.1 最小化时 `isMaximized()` 会变 false

Windows 上窗口最小化后 `isMaximized()` 返回 false。若无条件采信，把最大化窗口最小化再关闭，`maximized` 就被写成 false，下次启动回不到最大化。做法：**最小化期间沿用上一次已知的最大化值**。

### 3.2 最大化/最小化时要用 `getNormalBounds()`

`getBounds()` 在最大化时返回铺满屏幕的矩形，直接存会「还原后越开越大」。`getNormalBounds()` 才是还原尺寸 —— e2e 专门断言了这条（保存的是 1000×700，不是 1936×1048）。

### 3.3 副屏拔掉后不能把窗口还原到屏幕外

`fitBounds()`：先按 `MIN_WIDTH/MIN_HEIGHT` 与 `MAX_SIZE` 收敛脏数据，再找「有 ≥80px 重叠」的那块屏；找不到（原副屏已拔）→ 回默认居中；找到则把宽高压进该屏工作区，并把左上角拉回可见范围（`y >= workArea.y`，标题栏必须露出来）。

## 4. 刻意的行为取舍

- **最小化只记录、不还原**：启动即最小化会让用户以为「应用没起来」。`window-state.json` 里仍如实记 `minimized: true`，但下次启动按正常窗口显示（尺寸/位置照旧）。e2e 第 4 次启动验证了这条。
- **保存失败静默**：退出链路上绝不能因为磁盘写不进去而弹窗或崩；只 `console.warn` 一条，主流程继续。同理，写失败会清掉 `.tmp`，不留半截文件。
- **损坏文件会被覆盖**：读失败用默认值启动，退出时正常 flush，于是下一次读到的是合法 JSON（自愈）。

## 6. 排查记录（踩过的坑）

1. **PowerShell 变量名不区分大小写**：辅助脚本里 `$H`（高度参数）和 `$h`（窗口句柄）是同一个变量，`SetWindowPos` 的 `cy` 实际收到 HWND → 窗口被撑到 65535 高，状态文件随之写坏。改名 `$BoxX/$BoxY/$BoxW/$BoxH` 后一次通过。
2. **Windows 最大化矩形比工作区大**：不可见边框会探出约 8px（`1936×1048` vs `1920×1032`），断言要留余量，否则误判。
3. **最小化后 `GetWindowRect` 返回 -32000**：最小化断言只看 `showCmd`，不看矩形。
4. 短生命周期进程里 `GetWindowPlacement` 的 `length` 字段必须显式赋值，否则 `showCmd` 恒为 0。

## 7. 已知限制

- 不记录全屏（`fullscreen`）与 DPI 缩放比例；换屏/改缩放时按新屏工作区收敛尺寸。
- 单窗口项目，未做多窗口状态（解析窗口/弹幕覆盖层不持久化）。
- `--user-data-dir` 与 `PF_WINDOW_STATE` 都可用于测试隔离，生产不设置。
