# P32 媒体库界面优化

用户诉求：**「媒体库界面优化」**。

先按现状截图取证（`.libcheck/ui`，mock 6 个任务 / 8 部收藏 / 3 条继续观看），再逐条改。

## 改之前的问题

### 下载内容

| 问题 | 说明 |
|---|---|
| 六张卡长得一模一样 | 缩略图都是同一个蓝紫渐变空块 + 一个居中播放键，只有左上角 `HLS/MP4` 有区别，找片只能靠读标题 |
| 没有搜索、没有筛选 | 工具条里什么都没有（收藏 tab 的巡检控件占了右侧）；任务一多只能滚动找 |
| 进度条没有信息量 | `ready` 任务也画一条 100% 的条，和「就绪」徽章重复 |
| 时间精确到秒 | 「添加于 2026/11/1 07:58:31」，噪声大且占宽 |
| 状态与缓存档同权重 | 两个都是小 pill，「下载中」和「预缓存」看起来一样重要 |
| 没有移除入口 | 想删任务只能去「任务」页 |

### 收藏

| 问题 | 说明 |
|---|---|
| **海报溢出卡片（真 bug）** | `img` 是 flex item，`width/height:100%` 约束不住固有宽度（实测卡片 145，内容 240），居中后播放键被推到卡片右边缘外面、被 `overflow:hidden` 裁掉半个，海报也压出卡片边界 |
| 元信息换行 | 「年份 / 类型 / 备注」用 `flex-wrap: wrap`，卡片一窄就折两行，同时段卡片标题基线错位、下半截高度参差 |
| 两个「自动巡检」 | 一个是上次结果 `自动巡检 +3 集 · 11:16`，一个是间隔下拉，文案撞车像重复控件 |
| 播放入口重复 | 海报上一个圆形播放键 + 卡片底部又一个「播放」按钮 |
| 继续观看无限铺 | 把所有进度记录都铺出来，和下方收藏网格重复占首屏 |

## 改成了什么

### 1. 修海报溢出

`img` 脱离 flex 流：`position: absolute; inset: 0; object-fit: cover`。
根因不是尺寸没写，而是它作为 flex item 会被固有宽度撑开容器。

### 2. 下载卡缩略图「一卡一色」

- 色相由标题哈希决定（`hsl(h 32% 20%)` → 同片每次进来看颜色一致）；
- 标题前两字做半透明水印（纯 ASCII 转大写，直链退化成协议名）；
- 播放键缩到 34px 挪到右下角，中间整块留给水印，不再互相压。

### 3. 信息层级

- 进度条只在 `0 < pct < 100` 且非失败时画（100% 不再画一条满格）；
- 缓存档位从 pill 降级为灰色小字，视觉权重让给状态徽章；
- 时间改相对时间：`刚刚 / 4 小时前 / 2 天前 / 2026-10-29`；
- 收藏卡把「+N 集」追更徽章移到标题行右侧（它是最重要的动态信息，不能被 meta 行的省略号裁掉），meta 固定单行，备注允许省略（完整值在 `title`）。

### 4. 工具条

- 下载：搜索框（标题 / 链接）+ 状态 chip（全部 6 / 进行中 3 / 已完成 2 / 失败 1，计数为 0 的禁用）+「添加于」相对时间；
- 收藏：搜索框 + 上次巡检结果小字 + 「巡检间隔」下拉 + 「检查更新」。文案撞车问题：下拉标签从「自动巡检」改为「巡检间隔」，小字从「自动巡检 +3 集」改为「上次 +3 集」。

### 5. 删除入口

下载卡 hover 出现右上角「×」（`opacity: 0 → 1`），走 `store.deleteTask()`，带 confirm 与失败 toast。
破坏性操作不静默：`window.confirm` 文案写明「缓存分片与记录会一并删除」。

### 6. 空态分两种

- **库为空**：保留大留白 + 图标 + 主按钮（引导去播放页/发现页）；
- **筛选无匹配**：轻量小卡（`max-width: 460px` 居中），文案说明是哪个词没匹配，按钮「清除筛选」。

两者混用会让人以为数据丢了。

## 踩到的坑

- **隐藏窗口截不到新帧**：`show:false` 时切路由后 `capturePage()` 拿到的还是上一页，哪怕 DOM 已经换好（`document.querySelector('.library-view')` 为真）。改成 `win.showInactive()` 后才一致；`invalidate()` 反复重绘不管用。
- **Vue 内联多语句不能用换行分隔**：`@click="a = 1 \n b = 2"` 会被当成单个表达式解析，报 `Unexpected token, expected ","`，必须抽成方法。
- 测试海报别用 SVG `linearGradient`：`<img>` 加载时 gradient 引用可能不生效、退成白底，反而看不清排版；用纯色块叠层。
