# P11 交付总结：追更后台巡检 / 地区与热门 / TMDB 评分

> 接续 P9（吸收 GYING 功能批次）的后续三项（P10 编号已被「第三方视频云解析」批次占用）。
> 记忆点：GYING 吸收清单中零外网依赖、纯聚合可做的部分至此全部完成；剩磁力/BT 片源属中长期。

## 1. 追更后台定时巡检

内核启动后自动追更，不再依赖用户手动点「检查更新」（对标 GYING 的追更体验）。

- **调度**：`pf-core` 启动 5 分钟（`AUTOSCAN_START_DELAY_SECS=300`）后首跑，之后每 6 小时（`AUTOSCAN_INTERVAL_HOURS=6`）一轮（`main.rs` §4.7 后台任务）。
- **共用逻辑**：`catalog.favorite.refresh` 的回拉对比逻辑抽为 `refresh_favorite_sources()`，RPC 与后台任务共用同一口径（首个非空剧集组、新快照不增则不动、手动补充片源跳过）。
- **状态落库**：settings 表 `catalog.autoscan.last_run_ms` / `catalog.autoscan.last_added`；新 RPC `catalog.favorite.autoscan`（`{}` 读状态、`{run:true}` 同步触发一轮并记录）。
- **前端**：媒体库收藏 tab 工具行显示「自动巡检 +N 集 · HH:mm」弱化文案（无更新显示「自动巡检无更新」），悬停说明间隔。

## 2. 分类流地区筛选 + 热门榜

- **地区筛选**：`catalog.category` 新增 `area` 参数，服务端按 `vod_area` 包含匹配（`pf-parser::cms::area_matches`，多候选关键词 `|` 连接：「大陆|内地」同时命中「中国大陆/内地/大陆」）。苹果CMS 列表接口无地区参数，客户端过滤是唯一可靠路径。
- **热门榜**：`sort` 参数（`time`=更新时间降序默认 / `hot`=收录站数降序），热门口径复用聚合键的收录站数（`sourceCount`），平局再按站内更新时间。
- **前端**：发现页分类 tab 筛选条重排为两行——「热门/最新 · 今日更新 · 大类」与「年份 · 地区（大陆/香港/台湾/美国/韩国/日本/英国/泰国）」。

## 3. TMDB 评分增强

- **Key 管理**：`catalog.tmdb.get/set`，存 settings 表 `catalog.tmdb.key`（空串=未配置）；配置入口在发现页源站管理面板底部（可选，无 Key 全链路静默降级）。
- **评分查询**：`catalog.tmdb.lookup`（name+year）→ TMDB `search/multi`（电影+剧集，`language=zh-CN`，8s 超时），年份匹配 `release_date`/`first_air_date` 前缀优先，无命中回退第一条；返回 rating/votes/title/poster/overview。
- **展示**：详情弹层加载完成后异步并入 `detail.tmdb`（不阻塞弹层），标题旁「★ 8.5」徽章（悬停显示评分人数）；store 侧按 `name|year` 缓存。
- **降级**：无 Key → `found:false, reason:"no-key"`；网络失败/无结果 → `found:false`，UI 不显示徽章。
